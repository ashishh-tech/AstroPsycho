- **Medical Astrology**: Insights into health vulnerabilities based on planetary afflictions.

## 🚀 Getting Started

### Prerequisites

You just need a standard modern web browser (Chrome, Firefox, Safari, Edge) to run this locally! No complex backend setups required.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ashishh-tech/AstroPsycho.git
   cd AstroPsycho
   ```

2. **Run it locally:**
   Since this is a client-side architecture, you can simply open `index.html` in your browser. 
   Optionally, serve it using any local server extension (e.g., Live Server in VSCode or Python's HTTP server) for the best modular script loading experience:
   ```bash
   python -m http.server 8000
   ```
   Then navigate to `http://localhost:8000`.
