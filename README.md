## 🚀 Blast Off (Local Setup)

</div>

Experience AstroPsycho beautifully rendered in your local browser space! Because it is entirely client-rendered with a custom JS Engine, you don't need a heavy backend.

```bash
# 1. Clone the project locally
git clone https://github.com/ashishh-tech/AstroPsycho.git

# 2. Enter the cosmic portal directory
cd AstroPsycho

# 3. Spin up a local server to enjoy module imports!
python -m http.server 8000
# OR
npx serve .
```

Navigate to `http://localhost:8000` to dive into the cosmos!
